# Scirocco 3.3.0 - 2026-11-01

Notice: Scirocco may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This beta adds HDR10+ dynamic metadata for HEVC and AV1 streams, makes the Remote Monitor honor
the client's HDR request, moves PyroWave's D3D12 conversion to a high-priority queue by default,
and hardens several privileged Windows paths. Nothing else changes compared to 3.2.0.

## Changes
- Added the `hdr_dynamic_metadata` option (off by default, Windows only). When on and the stream
  is PQ 10-bit HEVC or AV1, the host measures each frame's luminance on the GPU and adds HDR10+
  (SMPTE ST 2094-40) metadata to the video: a prefix SEI for HEVC, a metadata OBU for AV1. H.264,
  SDR, software-encoded and PyroWave streams are unchanged, and clients that ignore HDR10+ keep
  the static HDR10 metadata. There is no protocol change.
- The Remote Monitor virtual display now honors the client's HDR request. The host applies HDR on
  that exact display and reads the state back; HDR is used for capture only when the readback
  confirms it, otherwise the monitor falls back to SDR. A display shared with a normal game
  capture is only verified, not changed.
- PyroWave on Windows now converts frames with the D3D12 backend by default, on a high-priority
  compute queue (it falls back to normal priority, and the fallback is logged). Sessions using
  RTX HDR, or with `VIBESHINE_PYROWAVE_CONVERSION=d3d11` set, keep using D3D11.
- Hardened privileged Windows paths: the display helper is now authenticated over a private pipe
  that only SYSTEM can open, the elevated MSI payload is kept out of ProgramData, the install
  root must be a folder beneath Program Files, RTSS hooks must be signed and located in Program
  Files, web UI logins are rate-limited, the request buffer is capped and credentials are kept out
  of logs.

### Build and tests
- The Windows CI job saves its compiler cache from master builds only. This affects build times,
  not the host.
- Fixed the HDR10+ code failing to build with GCC 14 and the AMF test harness, and the RTSS
  signature check failing to compile with MinGW.

## Known issues
- Releases from this fork are unsigned.
