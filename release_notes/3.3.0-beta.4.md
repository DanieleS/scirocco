# Scirocco 3.3.0 - 2026-11-05

Notice: Scirocco may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This beta updates the bundled scry so the Final Fantasy VII Rebirth telemetry can say which area
the player is in. It also fixes the devices view, which revoked the telemetry and unlock
permissions every time a client was saved.

## Changes
- scry is pinned to 0.1.0-alpha.8. It can filter a list it reads, which the Final Fantasy VII
  Rebirth profile (contract 1.3) uses to report the location volumes the player stands in. A
  Zefiro view can then show the area's name and the region map.
- Fixed the devices view dropping a client's telemetry and unlock permissions. It masked
  permissions with an old copy of the full permission set that predates both, so loading a client
  removed them from the form and saving it sent them as revoked.

## Known issues
- Releases from this fork are unsigned.
