# Scirocco 3.3.1 - 2026-11-06

Notice: Scirocco may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This beta fixes the Windows installer. It rolls the installer back to the simpler install flow
of the earlier stable releases, after reports of failed installs and upgrades with the stricter
install-folder security checks added in 3.3.0.

## Changes
- Restored the Windows setup bootstrapper and MSI install actions to the earlier stable flow. The
  install-folder validation introduced in 3.3.0 (the install root must be a folder beneath
  Program Files, checks scoped to packaged files, replacement validation before the working host
  is removed) is removed, since it could block installs and upgrades. Other hardening in 3.3.0,
  such as the authenticated display helper pipe, is unchanged.
- The installer no longer deletes every `.txt` and `.log` file in the install folder during
  migration.
- Removed the install-root guard from the MSI, together with its build step and tests.

### From upstream Vibepollo
- The installer rollback above comes from upstream Vibepollo 2.0.6, which keeps the newer
  installer checks on its Canary builds for extended testing.

## Known issues
- Releases from this fork are unsigned.
