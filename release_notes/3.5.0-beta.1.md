# Scirocco 3.5.0 - 2026-11-28

Notice: Scirocco may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This beta smooths streaming to remote clients by spreading out the packets of small frames, and
fixes a crash that could happen when several clients connected at the same time, compared to 3.4.0.

## Changes
- Remote clients (packets of 1024 bytes or less) now receive every frame's packets a few at a time
  (4 at least, about half a millisecond's worth) instead of in a back-to-back burst, at the
  stream's own bitrate (10 to 50 Mbps), or faster for a frame that would take longer than the new
  `remote_pacing_ms` option (default 5, at most a third of a frame interval, 0 = send at once).
  This reduces packet loss and stutter on internet links. LAN clients, PyroWave and an explicit
  `pacing_max_bitrate_kbps` are unchanged. The option has a label in the web UI.
- Fixed a host crash when several clients connected at once: client certificates are now verified
  with a separate context per handshake, instead of one shared by all threads that one handshake
  could free while another was still using it.

## Known issues
- Releases from this fork are unsigned.
